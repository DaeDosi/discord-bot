# NexBot PIKU Collector (Chrome 확장)

PIKU 공개 랭킹 표를 **이미 렌더된 화면에서 읽어** NexBot 관리자에게 보냅니다.

## 왜 확장인가

Railway와 AWS 서울 EC2에서 PIKU에 접속하면 둘 다 **HTTP 403**입니다. 우회
(프록시·VPN·User-Agent 위장·쿠키 재사용·CAPTCHA 대응)는 하지 않기로 했으므로,
PIKU가 정상적으로 열리는 **운영자 브라우저**가 대신 읽습니다.

이 확장이 **하지 않는 것**:

- PIKU에 추가 요청을 보내지 않습니다(내부 `x.php`도 부르지 않습니다). 화면에
  이미 있는 DOM만 읽습니다.
- 쿠키·세션·헤더·원문 HTML을 보내지 않습니다.
- 표의 '보기 개수'를 대신 바꾸지 않습니다 — 서버측 표라면 그 조작이 곧 내부 API
  요청이 되기 때문입니다. 대신 무엇을 바꾸면 되는지 알려 줍니다.
- 어떤 secret도 저장하지 않습니다.

## 설치

1. Chrome 주소창에 `chrome://extensions` 입력
2. 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** 클릭
4. 이 폴더(`tools/piku-collector-extension`)를 선택

## 사용 절차

부문마다 아래를 반복합니다(여성 솔로 → 남성 솔로 → 그룹).

1. **Nexadmin에서 토큰 발급**
   `https://nexbot.shop/nexadmin` → `PIKU 수집(브라우저)` 탭 → 해당 부문의
   **`수집 토큰`** 버튼. 토큰은 **10분·1회용·그 부문 전용**이며 화면에 한 번만
   나옵니다.

2. **PIKU 정본 페이지 열기**

   | 부문 | 주소 |
   |---|---|
   | 여성 솔로 | `https://www.piku.co.kr/w/rank/8jGsHE` |
   | 남성 솔로 | `https://www.piku.co.kr/w/rank/7PqH44` |
   | 그룹 | `https://www.piku.co.kr/w/rank/7fXoNs` |

3. **표를 전부 펼치기** — 표 위의 '보기 개수'를 **100**으로 바꿉니다.
   여성/남성은 64행, 그룹은 32행이 모두 보여야 합니다.

4. **확장 실행** — 툴바 아이콘 클릭 → `읽기만 하고 확인`으로 먼저 점검합니다.
   행 수와 1위 이름이 맞는지 봅니다. 이 단계는 아무것도 보내지 않습니다.

5. **전송** — 토큰을 붙여 넣고 `이 페이지 읽어 보내기`.
   서버에는 **draft로만** 저장되며 공개되지 않습니다.

6. **이름 매핑 확정** — Nexadmin에서 해당 부문의 `매핑 검토` →
   `정확 일치 N건 확정`. 남은 미확정 항목은 후보 목록에서 직접 고릅니다.
   **이 단계를 건너뛰면 공개해도 순위가 빕니다**(확정된 매핑만 순위에 들어갑니다).

7. **세 부문이 모두 끝나면** `공개 전 확인`으로 변화를 본 뒤
   `세 부문 함께 공개`를 누릅니다. 하나라도 준비되지 않으면 버튼이 비활성이고,
   화면에 막힌 이유가 적혀 있습니다.

## 실패했을 때

확장은 실패를 **실패로** 표시하고 서버에도 실패로 남깁니다. 기존 데이터는
그대로 유지됩니다.

| 표시 | 뜻 | 할 일 |
|---|---|---|
| PIKU가 확인 화면을 표시했습니다 | 차단·CAPTCHA 화면 | **재시도하지 마세요.** 시간을 두고 브라우저에서 정상 접속되는지 먼저 확인 |
| N행만 보입니다 | 표가 다 렌더되지 않음 | '보기 개수'를 100으로 바꾸고 다시 |
| 랭킹 표를 찾지 못했습니다 | 페이지 구조가 바뀌었을 수 있음 | 운영자에게 보고 (파서 수정 필요) |
| N위 행: … | 그 행의 이름·곡·가수 또는 비율을 읽지 못함 | 운영자에게 행 번호와 함께 보고 |
| 토큰이 만료됐거나 이미 사용됐습니다 | 1회용 토큰 소진 | Nexadmin에서 새로 발급 |
| NexBot에 수집 경로가 없습니다(미배포) | HTTP 404 — nexbot.shop에 Collector relay가 아직 배포되지 않음 | 운영자에게 보고. **재시도하지 마세요** |
| 같은 내용을 방금 보냈습니다 | 중복 전송 차단 | 표를 갱신한 뒤 다시 |

## 곡·가수 구분 규칙

이름 칸은 `[스트리머] 곡 - 가수` 한 문자열입니다. **곡명에 ` - `가 포함된 경우
마지막 구분자를 곡·가수 경계로 사용합니다. 경계 또는 필수 값이 없으면 전체 수집을
중단합니다.**

예: `[피 네] HOLLOW HUNGER - OVERLOAD Ⅳ - OxT`
→ 곡 `HOLLOW HUNGER - OVERLOAD Ⅳ` · 가수 `OxT`

## 실패한 토큰과 재시도

- **NexBot 주소는 `https://nexbot.shop` 그대로** 둡니다. Railway 원본 주소를
  직접 넣지 마세요 — 전송은 nexbot.shop의 수집 경로를 거쳐 갑니다.
- **HTTP 404는 그 수집 경로가 아직 배포되지 않았다는 뜻**입니다. 토큰이나
  표의 문제가 아니므로 다시 눌러도 똑같이 실패합니다.
- **실패한 토큰은 재사용하지 마세요.** 1회용이라 상태를 알 수 없습니다.
  원인을 고치고 배포한 뒤 Nexadmin에서 **새로 발급**받으세요.
- 확장은 **자동으로 재시도하지 않습니다.** 수동으로도 연속 재시도하지 마세요.

## 자동 수집

기본 **꺼짐**입니다. 켜더라도 **이 PC와 Chrome이 켜져 있을 때만** 동작합니다 —
꺼져 있으면 그 시간대는 갱신되지 않으며, 그 사실이 관리 화면에 표시됩니다.
자동 공개도 기본 꺼짐입니다(사람이 보지 않은 데이터를 공개하지 않습니다).
